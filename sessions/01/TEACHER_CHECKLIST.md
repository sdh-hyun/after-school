## 비상 대안

- GitHub 로그인 실패: 짝과 전체 흐름을 관찰한 뒤 교사 로컬 저장소에서 branch·commit 수행
- 네트워크 실패: 각 PC의 로컬 저장소로 branch·commit까지 진행하고 push·PR은 다음 시간 첫 단계로 이관
- Fork 설치 실패: 브라우저 확인 후 가능하면 Git CLI, CLI도 어렵다면 교사 시범 저장소 사용
- 시간이 부족함: PR 제출까지만 필수, 충돌과 상세 구두 진단은 2회차 초반으로 이관
