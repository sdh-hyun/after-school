# 3회차 준비 자료 안내

주제는 **Unity GameObject와 Component를 연결해 작은 기능을 완성하고, 고장 난 장면을 디버깅하는 것**이다. 운영계획에 따라 120분, 예상 15명 기준으로 작성했다.

## 수업 전 읽을 순서

1. [LESSON_PLAN.md](./LESSON_PLAN.md) — 120분 진행과 15명 순회 평가 방식
2. [UNITY_PROJECT_SETUP.md](./UNITY_PROJECT_SETUP.md) — 정상·고장 장면 제작과 배포 전 검증
3. [TEACHER_CHECKLIST.md](./TEACHER_CHECKLIST.md) — 전날, 직전, 수업 중 체크
4. [ASSESSMENT.md](./ASSESSMENT.md) — 구두 질문, 현장 변경, 채점표
5. [STUDENT_HANDOUT.md](./STUDENT_HANDOUT.md) — 학생 배포용 설명과 실습 기록
6. [RETROSPECTIVE.md](./RETROSPECTIVE.md) — 수업 직후 실제 결과와 4회차 인계 기록

## 포함된 수업용 코드

`unity-scripts/`에는 다음 5개 기준 스크립트가 있다.

- `PlayerMover.cs`
- `Coin.cs`
- `ScoreManager.cs`
- `PlayerCollector.cs`
- `CoinSpawner.cs`

실제 Unity 프로젝트의 `Assets/Scripts`로 복사한 뒤 Unity가 생성하는 `.meta` 파일까지 저장소에 포함한다.
