특성화고 1·2학년 대상 C#·Unity 게임개발 심화반의 수업 준비 프로젝트입니다.

## 주요 문서

- [COURSE_PLAN.md](./COURSE_PLAN.md): 29회 전체 운영 기획
- [SESSION_PREP_TEMPLATE.md](./SESSION_PREP_TEMPLATE.md): 회차별 수업 준비 템플릿
- [AGENTS.md](./AGENTS.md): 새 Codex 작업에서 유지할 프로젝트 지침

## 새 회차 준비 방법

이 폴더에서 새 작업을 만든 뒤 다음처럼 요청합니다.

> COURSE_PLAN.md를 기준으로 3회차 수업을 준비해줘. 2시간 수업이고, 강의안·실습 과제·시험 문제·채점 기준·교사용 체크리스트까지 만들어줘.

직전 회차 결과를 알고 있다면 함께 적습니다.

> 6회차 준비해줘. 현재 잔류 학생은 11명이고, 5회차에 맵 생성·플레이어·전투·몬스터·UI 역할을 배정했어. 인터페이스 설계가 아직 덜 끝났고 Git 충돌을 어려워해.

각 회차 자료는 권장 경로인 `sessions/NN/` 아래에 저장하도록 요청하면 됩니다.
